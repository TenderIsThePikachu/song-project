<가사 입력 관련>
★. Phonemizer 설정 (가사 입력과 관련하여)
포네마이저 설정은 윳에 따라서, 그리고 사용 용도에 따라서 가장 적합한 것으로 바꾸시면 됩니다.
	(1) DIFFS (Diffsinger Phonemizer) :: 
영어/일본어 입력 시 일본어 발음으로 출력 (ex. 가사에 'a'입력 = 'ja/a' / ex2. 가사에 'あ'입력 = 'ja/a')
한글 입력 시 한국어 발음 입*출력 가능 (ex. 가사에 '아'입력 = 'ko/a')
영어 가사 입력 불가 (error)
	(2) DIFFS JA (Diffsinger Japanese Phonemizer) :: 
(1)과 동일
	(3) DIFFS KO (Diffsinger Korean Phonemizer) :: 한국어 로마자 윳 사용시 등
일본어 입력 시 일본어 발음으로 출력 가능 (ex. 가사에 'あ'입력 = 'ja/a')
영어/한글 입력 시 한국어 발음으로 출력 (ex. 가사에 'a'입력 = 'ko/a' ex2. 가사에 '아'입력 = 'ko/a')
ㄴ> 영어로 'gan', 혹은 한글로 '간' 입력 시 (ko/g, ko/a, ko/N으로 자동 조정)
영어 가사 입력 불가 (error)
	(4) DIFFS EN (Diffsinger English Phonemizer) :: 영어 단어가 포함된 윳 사용 시 등
일본어 입력 시 일본어 발음으로 출력 가능 (ex. 가사에 'あ'입력 = 'ja/a')
한글 입력 시 한국어 발음으로 출력 (ex. 가사에 '아'입력 = 'ko/a')
영어 입력 시 영어 발음으로 출력. 한 노트에 단어로 작성 시 발음을 알아서 변환해줍니다.
