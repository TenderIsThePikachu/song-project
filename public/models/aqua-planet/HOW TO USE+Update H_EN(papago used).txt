<Setting Up Later>

1. OpenUTAU -> [Tools] -> [Preferences] -> "Use Beta Version - [On]". (MultiDict)
2. Update after OpenUTAU reboot (Reboot after update)

3. If your computer isn't good, if it doesn't work because of performance, -
Lower Diffsinger => Lending Steps and Depth to find the appropriate value. 
(Recommended minimum rendering value> Steps 10~20, depth is also recommended to be lowered similarly.)
In order to ensure good quality, it is good to give a certain level and depth value. (The value is recommended when set to the lowest.)

You can change the ponemizer setting to the most suitable one depending on the UT and the purpose of use.
	(1) DIFFS (Diffsinger Phonemizer) :: 
When entering English/Japanese, output in Japanese pronunciation (ex. input 'a' in lyrics = 'ja/a' / ex2. input 'あ' in lyrics = 'ja/a')
Korean pronunciation can be input*output when entering Korean (ex. 'Ah' in the lyrics = 'ko/a')
Unable to enter English lyrics (error)
	(2) DIFFS JA (Diffsinger Japanese Phonemizer) ::

	(3) DIFFS KO (Diffsinger Korean Ponemizer):: When using Korean romanizer, etc
When entering Japanese, it can be output in Japanese pronunciation (ex. Enter 'あ' in the lyrics = 'ja/a')
When inputting English/Korean, output in Korean pronunciation (ex. input 'a' in the lyrics = 'ko/a' ex2. input 'a' in the lyrics = 'ko/a')
b> When entering 'gan' in English or 'gan' in Korean (automatically adjust to ko/g, ko/a, ko/N)

	(4) DIFFS EN (Diffsinger English Ponemizer):: When using UT with English words, etc
When entering Japanese, it can be output in Japanese pronunciation (ex. Enter 'あ' in the lyrics = 'ja/a')
When entering Korean, output in Korean pronunciation (ex. input 'ah' in lyrics = 'ko/a')
When you enter English, it is printed in English pronunciation. When you write a word on a single note, it converts the pronunciation into words.
